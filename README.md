# Happy Birthday Fajar 

A beautiful, interactive birthday surprise website created with **HTML, CSS, and JavaScript** for my best friend, **Fajar**, on her **20th birthday**.

This project is a digital birthday gift filled with love, memories, and heartfelt wishes to make her special day unforgettable.



##  Features

-  Passcode Protected (Passcode: 3004)
-  Pink aesthetic design
-  Birthday welcome screen
-  Beautiful photo gallery
-  Heartfelt friendship letter
-  Interactive gift section
-  Floating heart animation
-  Responsive design
-  Background music support
-  Smooth UI and animations


##  Technologies Used

##  How to Run

1. Download or clone the repository.
2. Open the project folder in Visual Studio Code.
3. Add your images inside the `images` folder.
4. Add your music file (`birthday.mp3`) inside the `music` folder (optional).
5. Open `index.html` using Live Server or any web browser.
6. Enter the passcode **** to unlock the surprise.
